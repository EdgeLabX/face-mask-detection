# Face Mask Detection using Edge-AI

Overview

This project presents a real-time Face Mask Detection and Classification system using Artificial Intelligence and Deep Learning techniques. The system is designed to detect and classify face mask wearing conditions in real-time for public and private environments.

The proposed solution is implemented using advanced YOLOv5 Object Detection models:

YOLOv5s
YOLOv5l

The system can efficiently:

Detect face masks in real-time
Classify mask wearing conditions
Count detections
Store detection logs into CSV files with timestamps
Run on Edge AI hardware platform
